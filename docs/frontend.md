# 网页前端

前端位于 `frontend/`，使用 React、TypeScript、HeroUI、Vite 和 Tailwind CSS，通过 pnpm 管理依赖。

## 页面与使用

启动服务后访问 `http://127.0.0.1:8000/`，输入后端配置中的 `app.api_token` 登录。从根路径登录默认进入首页；直接打开其他页面时，登录后会进入对应页面。

| 页面 | 路径 | 主要功能 |
| --- | --- | --- |
| 首页 | `/index` | 全量统计、7 天趋势、最近更新的 3 条操作 |
| 邮箱工作台 | `/inbox` | 创建邮箱、搜索地址、收件阅读、清除失效邮箱 |
| 供应商 | `/providers` | 启用开关、供应商配置编辑 |
| 操作记录 | `/operations` | 历史记录、处理状态、按操作 ID 查询 |
| 系统配置 | `/settings` | 编辑并保存系统配置 |

各页面都有独立 URL，支持书签、直接访问、刷新和浏览器前进后退。

- **创建邮箱**：在邮箱工作台选择供应商与有效期，提交后等待后台处理。完成后自动打开新邮箱；网络中断时可通过“继续上次创建”重试原请求。
- **查找与翻页**：“我的邮箱”和“操作记录”每页 5 条，邮件列表每页 20 条。邮箱搜索按完整地址匹配，回车搜索后从第一页显示结果。
- **阅读邮件**：支持复制地址和正文。邮件按纯文本展示，不执行 HTML、脚本或加载外部图片。当前供应商仅支持创建和收件。
- **过期只读**：邮箱到期后停止收发，历史邮件仍可查看。没有缓存邮件时显示“没有历史邮件”。刷新页面或重启服务不会清除已保存内容。
- **清除邮箱**：点击“清除失效邮箱”，核对弹窗数量后确认。统计包含全部失效邮箱，不受搜索和分页影响；清除本地邮箱及邮件缓存，保留操作记录。待清除集合发生变化时需重新确认。
- **修改配置**：供应商开关直接保存；其他供应商设置在编辑弹窗中保存，系统设置在系统配置页保存。详细字段、生效方式和配置文件位置见 [配置说明](configuration.md)。

首页每 10 秒更新，离开首页或标签页隐藏时暂停轮询。邮箱工作台每 5 秒刷新本地缓存，也可手动刷新；过期邮箱仅保留手动读取。页面刷新成功表示本地查询成功，上游收件情况请结合最近同步时间与同步错误判断。

首页统计不受邮箱分页或搜索影响。趋势日期使用 UTC，新增邮件按缓存入库时间统计；清除数据后相关统计会减少，操作历史保留。统计口径与接口见 [API 说明](api.md)。

## 外观与会话

右上角可切换浅色、深色主题及中文、英文，默认使用浅色和中文。偏好保存在浏览器 `localStorage`，刷新和退出后仍保留，同源标签页会同步；邮件原文不会被翻译。

访问令牌保存在当前标签页的 `sessionStorage`，刷新后可继续使用，退出登录时清除。业务请求自动携带 `Authorization: Bearer`。该令牌拥有整个服务的访问权限，不是独立用户账户；前端构建产物不包含令牌或供应商凭据。

## 开发与构建

需要 Node.js 22.13+ 和 pnpm 11.0.9。后端环境准备见 [本地启动](../README.md#本地启动)。

在项目根目录启动 API 和 Worker：

```bash
uv run python run.py --reload
```

另开终端启动前端：

```bash
cd frontend
pnpm install --frozen-lockfile
pnpm dev
```

访问 `http://127.0.0.1:5173/`。Vite 将 API 请求转发到 `http://127.0.0.1:8000`；后端端口变化时同步调整 `frontend/vite.config.ts`。统一启动入口不启动 pnpm；`--reload` 只重载 API 代码，修改 Worker 代码后需重启入口。

在 `frontend/` 构建生产页面：

```bash
pnpm build
```

产物写入 `frontend/dist/`，由 API 提供静态访问。随后在项目根目录运行 `uv run python run.py`，打开 `http://127.0.0.1:8000/` 即可使用，无需运行 Vite。

Docker 会一并构建前端，部署步骤见 [Docker 部署](deployment.md)。修改前端源码后需重新构建产物或镜像。使用反向代理时，除 `/assets` 静态资源和 API 路径外，也需转发上表中的页面路径，保证直接访问和刷新可用。

## 验证

在 `frontend/` 执行：

```bash
pnpm check
pnpm format:check
pnpm build
pnpm exec playwright install chromium
pnpm test
```

这些命令依次检查 TypeScript 类型、格式、生产构建和浏览器行为。Playwright 自动启动独立的 Vite 测试服务，使用模拟 API，不创建真实供应商邮箱。

已安装 Chrome 时，可改用以下命令运行浏览器测试（Linux/macOS）：

```bash
PLAYWRIGHT_CHANNEL=chrome pnpm test
```
