# 22.do

## 能力与配置

供应商 ID：`22-do`。接入免费网页的匿名邮箱流程，支持创建邮箱、读取邮件列表和正文；不支持发件、远端删除、附件或 Webhook。无需填写 22.do 账户密码或正式 API token。

```yaml
providers:
  22-do:
    enabled: true
    index_url: https://22.do/
    base_url: https://22.do
    timeout_seconds: 15
    impersonate: chrome110
    max_ttl_seconds: 86400
    proxy: null
```

公共参数与热更新规则见 [配置说明](../configuration.md)。已有配置未列出本供应商时，可在网页“供应商”面板启用并保存。适配器使用配置中的代理，不要求常驻浏览器；随机出口能否持续访问仍取决于上游，未做跨 IP 保证。

## 收件流程

| 操作 | 请求 | 处理 |
| --- | --- | --- |
| 分配地址 | `GET /inbox` | 从页面读取邮箱地址与剩余有效期 |
| 申请令牌 | `POST /action/mailbox/applyToken` | 提交邮箱地址与 UUID，取得 token 和过期时间 |
| 邮件列表 | `POST /action/mailbox/message` | 携带 Bearer token，提交 `email`、`lastime` |
| 邮件详情 | `GET /content/{messageId}` | 提取正文 iframe 地址 |
| 邮件正文 | `GET /view/...` | 将 HTML 转为纯文本，不执行脚本或加载图片 |

仅允许请求同一供应商源下的正文地址，不跟随 HTTP 重定向。空列表的 `data: null`、`false`、`[]` 均按暂无邮件处理；网页变化或格式不符会产生同步错误，不把详情页的导航、广告当作正文缓存。

邮箱凭据加密保存在现有数据库中，重启后继续访问原地址；令牌失效时重新为原地址申请，不创建替代邮箱。邮箱到期时间取本地请求有效期和上游剩余寿命的较早值，刷新令牌不会延期邮箱。

## 地址复用与历史邮件

22.do 可能分配 Gmail、Googlemail、Outlook、Hotmail 的别名地址，也可能分配自有临时域名。地址不代表新注册的独立邮箱账户。调研时曾观察到刚分配的地址已有历史邮件，因此适配器只接收本次分配开始之后、收件人与完整地址匹配的邮件，保留 `+` 后缀进行区分。

这项过滤不能把上游共享邮箱变成独占邮箱。实测无原浏览器 Cookie、使用不同 UUID 仍可为测试地址申请 token，不应将免费邮箱视为只有本服务能访问的私有收件箱。

本次测试中，读取正文后同一邮件仍在列表中，因此使用普通收件模式，按稳定的 `messageId` 在本地去重。邮箱到期后停止同步，历史缓存保留至用户手动清除。

## 故障与验证

创建请求没有上游幂等保证；可能已分配地址的失败会标记为不确定，不自动重放创建。限流、拒绝访问、无效响应按供应商错误返回，由 Worker 退避；日志不包含 token、代理密码或上游原始响应。

2026 年 10 月的调研已完成 20 个不同地址的串行获取与列表读取，并通过用户发送的测试邮件验证列表、详情页和 iframe 正文链路。尚未验证无限批量、跨 IP 稳定性或完整的 24 小时存续。离线测试使用模拟响应，不创建真实供应商邮箱。

此适配器使用网页接口，并非 `/api/v2` 的账户 API。网页接口可能随站点变化；站点正式 API 文档对镜像代理和二次封装有使用限制，部署时应确认适用范围。站点入口与说明：`https://22.do/inbox`、`https://22.do/document`。
